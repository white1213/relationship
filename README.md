# 关系图谱

一个运行在 Android 上的人际关系和家庭关系管理应用：核心数据本地加密保存、离线中文称谓推理，AI 提取按需联网。

## 当前功能

- 一句话建关系：在人物页输入「老王是小明的舅舅」，纯本地解析、预览确认后写入
- 支持描述式链式表达（「妈妈的哥哥」「爸爸的姐姐的儿子」）和排行前缀（「三舅」「二姑」）
- 句中提到的人物不存在时，在预览里一键补建（姓名+性别）
- 人物详情页「添加亲人」快建面板：按配偶/直系/旁系/姻亲选称谓，方向自动确定
- 堂表称谓自动细化到「表哥/表弟/堂姐/堂妹」；信息缺失时给出「表哥/表弟」式兜底而非笼统词
- 堂/表判定由称谓语义与配偶性别共推决定，父亲性别缺失不再导致退化
- 称谓不够具体时，人物详情页提示补全性别、生日或长幼，可一键补性别
- 关系编辑表单的人物选择支持按姓名、电话搜索
- 创建、编辑和删除人物资料
- 记录电话、生日、地址、标签、备注和头像
- 记录家庭与社交关系，并允许同一对人物存在多种关系
- 总关系图浏览、缩放、拖动、搜索和分类筛选
- 家谱、社交、全部三种视图，家谱按辈分分层排列
- 设置唯一的「我」，作为辈分和图谱排列基准
- 图谱节点显示头像和完整姓名，并根据家庭、社交、混合关系显示不同颜色
- 配偶、兄弟姐妹和社交关系使用不同颜色与线型
- 关系文字默认隐藏，点选人物或放大图谱后显示
- 内置可关闭的图谱图例
- 点选人物后淡化无关节点，只保留直接关系文字
- 可只看某个人的直接关系、祖先、后代或完整分支
- 搜索结果唯一时自动居中并聚焦对应人物
- 根据父母子女和配偶关系推理祖辈、旁系、姻亲及继亲候选
- 候选关系可一键确认或永久忽略，不会自动写入
- 图谱聚焦人物时以虚线显示相关候选关系
- 配偶子女可确认添加为子女或仅保留继亲关系
- 支持嫂子、弟媳、姐夫、妹夫、小叔子和大伯子等姻亲称谓
- 支持大爷、大娘、叔叔、婶婶、姑父、舅妈和姨父等姻亲称谓
- 夫妻关系可设置随夫家、随妻家或双方各自称呼
- 支持母亲/女儿单向关系以及舅舅、姑姑、叔叔家子女的堂表亲推理
- 不知道生日时可在人物详情手动设置年长、年幼或同龄
- 内置母亲/女儿、姐姐、姐夫、姑姑、姑父、表兄弟姐妹和堂兄弟姐妹关系
- 个性化称谓与推导优先使用生日和手动长幼信息
- 图谱提供简洁关系与完整关系两种显示模式
- 一键整理当前图谱并支持 5 秒内撤销
- 关系新增、修改、删除均支持撤销（Snackbar 撤销入口，最多 20 步）
- 保存关系前自动做辈分环、祖孙婚与代际矛盾检测，弹窗拦截错误关系
- 图谱可导出 PNG 位图与 SVG 矢量图，整图自适应并带关系称谓标签
- 支持人物合并：迁移全部关系、标签与备注，合并后可一键撤销
- 生日支持农历（含闰月），可标记已故并录入忌日，已故节点自动置灰并带「故」徽章
- 生日与忌日本地提醒通知，每天上午 9 点左右检查，不联网
- 称谓查询页可查看任意两人的完整关系路径（本地算法，辅助远亲识别）
- 支持 GEDCOM (.ged) 导入导出；导入数据全部先进入待确认清单，不直接覆盖数据库
- AI 支持粘贴文本提取人物和关系，结果全部为待确认候选，确认后才写入
- AI 设置支持自定义提示词（追加或替换默认提示词）
- 大量自定义关系类型可通过搜索选择，新增入口固定在列表顶部
- 图谱页可进入独立的横屏全屏显示
- 称谓查询页可选择两个人查看双方称呼
- 可通过兼容 OpenAI 的 API 配置 AI 助手
- AI 只生成待确认操作，确认后才会修改人物或关系
- 6 位以上数字密码，可配合指纹或面容解锁
- 离开 1 分钟后重新锁定，熄屏立即锁定
- 使用单独密码导出和恢复加密备份
- 核心数据和备份不依赖账号或云同步
- 只有配置并启用 AI 后才会发送关系摘要到用户指定的 API

## 安装 APK

**从 GitHub Releases 下载（推荐）**：打开本仓库的 [Releases 页面](https://github.com/white1213/relationship/releases)，每个版本都附有可直接安装的 APK（最新版为 `relationship-graph-v1.9.0.apk`）。

> ⚠️ 签名变更提示：v1.9.0 起签名统一为项目自带密钥，与 v1.8.1 及更早版本**无法覆盖安装**。从旧版升级：先在旧版内导出 `.rgbackup` 备份 → 卸载 → 安装新版 → 恢复备份。v1.9.0 之后各版本签名一致，可直接覆盖升级。

本地构建出的 APK 位于仓库目录 `dist/`（该目录自 v1.9.1 起不再提交进 git，日常下载请走 Releases）。

把 APK 传到 Android 8.0 及以上手机后打开。系统首次提示时，允许当前文件管理器“安装未知应用”。

## 数据安全

- 数据保存在应用私有目录的加密数据库中。
- 密钥由 Android Keystore 管理。
- 核心数据不会主动上传；启用 AI 后会将人物姓名和关系摘要发送到用户配置的服务。
- 系统云备份和设备迁移已关闭。
- 导出的 `.rgbackup` 文件使用单独设置的密码加密。
- App 密码和备份密码均无法联网找回，请妥善保管并定期导出备份。

## 使用 Android Studio

1. 使用 Android Studio 打开本目录。
2. 等待 Gradle 同步完成。
3. 连接 Android 8.0 及以上手机。
4. 点击 Run 运行，或执行 `assembleDebug` 构建调试版 APK。

开发环境要求：JDK 17、Android SDK 35（Build Tools 35）；项目使用 Gradle 8.11.1、Android Gradle Plugin 8.7.3、Kotlin 2.1.0（打开目录后 Gradle 会按 wrapper 自动下载）。

## 本地构建命令

```powershell
.\gradlew.bat testDebugUnitTest assembleDebug lintDebug
```

正式构建文件会生成在：

```text
app/build/outputs/apk/debug/app-debug.apk
```

## 签名配置

签名口令不进版本库，构建时从项目根目录的 `keystore.properties` 读取。首次构建前，把 `keystore.properties.example` 复制为 `keystore.properties` 并按需修改：

```properties
storeFile=.signing/debug.keystore
storePassword=android
keyAlias=androiddebugkey
keyPassword=android
```

- `storeFile` 支持仓库相对路径（相对项目根目录）或绝对路径。
- 未创建 `keystore.properties` 时：debug 构建使用 Android 默认调试签名；release 构建产物为未签名 APK。
- v1.9.0 起发布到 Releases 的 APK 均使用仓库自带的 `.signing/debug.keystore` 签名，后续版本保持一致，可互相覆盖安装。
- 正式发布请使用固定的一把钥匙并妥善备份 keystore 文件和 `keystore.properties`；更换签名后已安装用户将无法覆盖安装。

## 已知限制

- 称谓推理的堂/表判定在「同性伴侣」数据下可能推错方向，此时显示「堂/表哥」式双称谓兜底（称谓具体化依赖异性家庭模型）。
- 一句话录入只支持「A 是 B 的称谓」句式：人名中不能含「是/的」二字；「爷爷的儿子」这类多解表述暂不支持，会明确报错而不是猜测。
- 家庭类关系在同一对人之间只允许一条同类型记录，保存时会拦截；社交类关系（同学、同事等）不受限制。
